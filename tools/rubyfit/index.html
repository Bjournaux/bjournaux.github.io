RubyFit

Pressure from ruby (Cr³⁺:Al₂O₃) fluorescence spectra. Runs entirely in your browser: files are never uploaded.

Created by Baptiste Journaux & Chris Woodburn, UW Planetary Mineral Physics Laboratory, University of Washington. Released under the GPL-3.0 license.

Method

  • R1 and R2 are fitted together, as two peaks on a cubic background, by least squares (Levenberg–Marquardt) in a window around R1 (Settings). Uncertainties come from the fit covariance.
  • Line shapes: Pearson VII (default), Lorentzian, their split (asymmetric) versions, and Voigt, computed with the Faddeeva function (Weideman 1994).
  • The pressure comes from the shift of R1 from λ₀, its wavelength at ambient pressure. In Pair, λ₀ is a reference ruby at the same temperature. In Single spectrum, it is a value you enter, moved to the sample temperature by a temperature correction.

Spectrum files and file names

Spectrum files

  • CSV or TXT (also .dat, .asc, .xy, .prn, .tsv), one spectrum per file: wavelength in nm in the first column, intensity in the second.
  • Columns separated by commas, semicolons, tabs or spaces. A decimal comma works with semicolons, tabs or spaces (694,123;1234), not with comma-separated columns.
  • Header, comment and instrument metadata lines are skipped. If a header names the columns (Wavelength and Intensity or Counts), those columns are used wherever they are.
  • Wavelengths in ångström (R1 near 6943 Å) are converted to nm automatically, with a note on the fit. Wavenumbers or Raman shift (cm⁻¹) and pixel numbers are refused with a message: export the spectrum in nm.

File names

For Pair and Batch, the file name says which ruby a spectrum comes from. Separate the words with _, - or spaces, for example:

ice6_inside_297K_ruby3_044.csv → sample ruby 3 at 297 K
ice6_outside_297K_ruby1_012.csv → reference ruby 1 at 297 K

Roleinside, chamber, sample or hp = sample ruby (in the cell); outside, backside, reference or ref = reference ruby (ambient pressure). The words can be changed in Settings. A name with no role word is treated as a sample.
TemperatureA number followed by a capital K: 297K, 297.5K, 297 K, 297_K, T297K. Give it in kelvin and only once per name, and do not use K for anything else (10K_counts would be read as 10 K). Not read: 297k, 24C, 297Kelvin. In Single spectrum it fills in the sample temperature; the temperature-dependent scale (Wei et al. 2024) also uses it in Pair and Batch.
Rubyruby followed by a number: ruby3, ruby_3, ruby-3 (ruby03 is the same ruby). Repeat spectra of one ruby must share the number; keep the spectrum number separate (ruby3_044, not ruby_044, which would be read as ruby 44).

Reference and sample spectra should be at the same temperature: Pair warns when the temperatures in the names differ.

Sample and reference rubies are paired by temperature. Everything read from the names (role, temperature, ruby) is shown in the Batch table and can be corrected there.

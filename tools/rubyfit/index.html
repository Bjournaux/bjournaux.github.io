R1 moves by ≈0.007 nm per K (≈18 MPa per K), so λ₀ is moved from the temperature it was measured at to the sample temperature. 694.22 nm is a literature value: an ambient-pressure ruby measured on your spectrometer is more accurate, and at the sample temperature it needs no correction (Pair mode).

Fit settings

Spectrum files and file names

Spectrum files

  • CSV or TXT (also .dat, .asc, .xy, .prn, .tsv), one spectrum per file: wavelength in nm in the first column, intensity in the second.
  • Columns separated by commas, semicolons, tabs or spaces. A decimal comma works with semicolons, tabs or spaces (694,123;1234), not with comma-separated columns.
  • Header, comment and instrument metadata lines are skipped. If a header names the columns (Wavelength and Intensity or Counts), those columns are used wherever they are.
  • Wavelengths in Å, wavenumbers or Raman shift (cm⁻¹) and pixel numbers are refused with a message: export the spectrum in nm.

File names

For Pair and Batch, the file name says which ruby a spectrum comes from. Separate the words with _, - or spaces, for example:

ice6_inside_297K_ruby3_044.csv → sample ruby 3 at 297 K
ice6_outside_297K_ruby1_012.csv → reference ruby 1 at 297 K

Roleinside, chamber, sample or hp = sample ruby (in the cell); outside, backside, reference or ref = reference ruby (ambient pressure). The words can be changed in Settings. A name with no role word is treated as a sample.
TemperatureA number followed by a capital K: 297K, 297.5K, 297 K, 297_K, T297K. Give it in kelvin and only once per name, and do not use K for anything else (10K_counts would be read as 10 K). Not read: 297k, 24C, 297Kelvin.
Rubyruby followed by a number: ruby3, ruby_3, ruby-3 (ruby03 is the same ruby). Repeat spectra of one ruby must share the number; keep the spectrum number separate (ruby3_044, not ruby_044, which would be read as ruby 44).

Sample and reference rubies are paired by temperature. Everything read from the names (role, temperature, ruby) is shown in the Batch table and can be corrected there.
